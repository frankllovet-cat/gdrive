Privacy Policy

Last updated: 2026

gdrive ("the app", "the tool") is a self-hosted, open-source command-line utility that synchronises a local folder with the user's own Google Drive account, using the Google Drive API through rclone. It is run by the user on the user's own computer(s). There is no server operated by the developer, and no data is transmitted to the developer.

What Google user data the app accesses

With the user's explicit consent (the OAuth authorisation screen), the app requests the Google Drive scope https://www.googleapis.com/auth/drive. This allows the app to read, create, modify and delete files and folders in the Google Drive account the user authorises. The app only accesses the files and folders that the user chooses to synchronise.

How the data is used

The Google Drive data is used for one purpose only: to keep the user's chosen local folder and their Google Drive synchronised — downloading files that are newer or missing locally, and uploading files that are newer or missing in Drive. No Google user data is used for advertising, profiling, analytics, or any other purpose.

How the data is stored and shared

  • File content moves only between the user's own computer(s) and the user's own Google Drive account, at the user's direction. It is never sent to the developer or to any third party.
  • The OAuth credentials (client ID, client secret and access/refresh tokens) are stored locally on the user's own machine, in the rclone configuration file, readable only by the user's account.
  • The app includes no analytics, telemetry, tracking, or crash reporting.
  • The developer has no access to, and does not collect, receive, store or process, any of the user's Google user data.

Data retention and deletion

Because the app runs entirely on the user's own machine and the data stays in the user's Google Drive, the user is in full control of retention:

  • Delete files in Google Drive or locally at any time; the next sync propagates the change.
  • Remove the locally stored credentials by deleting the relevant rclone remote (rclone config delete <name>).
  • Revoke the app's access at any time from the Google account's Security → Third-party apps page.

Limited Use disclosure

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Google user data is used only to provide the synchronisation feature, is not transferred to third parties except as necessary to provide that feature, is not used for advertising, and is not read by humans except with the user's explicit consent or as required by law.

Children

The app is not directed at children and does not knowingly collect data from anyone.

Changes to this policy

This policy may be updated from time to time. Material changes will be reflected on this page with an updated date.
