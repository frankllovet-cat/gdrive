gdrive

Two-way Google Drive sync for Linux

gdrive is a single shell script that keeps a local folder in two-way sync with Google Drive, built on rclone bisync and run from cron. Whichever side has the newer file wins, and deletions propagate in both directions — effectively a self-hosted "Google Drive for Desktop".

  • Two-way sync, newest file wins
  • Deletions propagate both ways
  • Conflicts preserved (older copy kept)
  • Runs from cron with a lock so runs never overlap
  • Self-rotating, compressed log

Source and setup instructions: github.com/frankllovet-cat/gdrive.
